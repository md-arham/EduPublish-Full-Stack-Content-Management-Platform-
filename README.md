> Scalable Medium-clone web application with JWT authentication and NETRA API integration, facilitating 2,000+ student publications while implementing robust content moderation and database management APIs that achieved 95% uptime across hosted environment.

## 🚀 Key Features

- **📝 Student Publishing Platform**: Complete Medium-like experience for educational content
- **🔐 JWT Authentication**: Secure user authentication and session management
- **🎓 NETRA API Integration**: Student verification and attendance-based access control
- **📊 Content Moderation**: AI-powered content filtering and manual review system
- **📈 Analytics Dashboard**: Real-time insights into publication metrics and user engagement
- **🌐 Multi-tenant Architecture**: Support for multiple educational institutions
- **📱 Responsive Design**: Seamless experience across desktop and mobile devices

## 🛠️ Tech Stack

### Frontend
- **Framework**: React.js 18+
- **Styling**: CSS3, Responsive Design
- **State Management**: Redux/Context API
- **UI Components**: Custom component library
- **Authentication**: JWT token management

### Backend
- **Runtime**: Node.js with Express.js
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT with bcrypt encryption
- **APIs**: RESTful API design
- **External Integration**: NETRA API for student verification

### Infrastructure
- **Hosting**: Cloud-based deployment
- **Database**: MongoDB Atlas/Self-hosted
- **Content Delivery**: Optimized static asset delivery
- **Monitoring**: Real-time performance tracking

## 📋 Prerequisites

- Node.js 16.0 or higher
- npm or yarn package manager
- MongoDB 4.4+
- NETRA API credentials (for student verification)
